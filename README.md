A personal portfolio website showcasing my profile, technical skills, selected projects, and experience in web development.

Designed to present my work through a clean, modern, and responsive interface, highlighting both software development projects and UI/UX design explorations.

This portfolio represents my journey and work as a Web Developer, with a focus on Full Stack Web Development.

## Getting Started

### Prerequisites

- Node.js
- npm

### Installation

1. Clone the repository:

   ```bash
   git clone https://github.com/YahyaAlifandi/NAMA-REPOSITORY.git
   ```

2. Navigate to the project directory:

   ```bash
   cd NAMA-REPOSITORY
   ```

3. Install dependencies:

   ```bash
   npm install
   ```

4. Run the development server:

   ```bash
   npm run dev
   ```

5. Open the local URL displayed in your terminal.

## Build for Production

To create an optimized production build:

```bash
npm run build
```

To preview the production build locally:

```bash
npm run preview
```
